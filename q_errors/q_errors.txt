Q ERRORS
========

PURPOSE
Checks poetry lines (marked with \q, \q1, \q2) for structural problems that
are common formatting or typesetting errors in Bible translation manuscripts.

PROBLEMS DETECTED
  1. Final punctuation followed by text — a sentence-ending mark (e.g., period)
     appears in the middle of a poetry line rather than at the end.
  2. Double verse markers — two \v markers appear on the same poetry line.
  3. Text before a verse marker — content appears before \v instead of after it.
  4. Hanging word (optional) — a line ends with non-final punctuation (e.g., a
     comma) followed by only a single word before the next poetry line.

HTML REPORT
  In addition to the results list, running the check writes an HTML report
  (QErrorsReport.html) to the project folder and opens it automatically.
  Findings are grouped by error type, and each entry shows the full poetry
  line with the specific problem highlighted in red -- including a slightly
  larger font for a bare final period, which is easy to miss otherwise.

HOW TO USE
1. Install the Phils Custom (cms) Checks plugin with Install_Phils_tools.exe. Everything comes with the plugin: nothing has to be copied into the cms folder. References in the HTML report can be clicked to show that place in Paratext. The first click makes the browser ask whether to open ParatextGoTo, and Paratext follows only when the text window's scroll group follows other programs.
2. In Paratext, choose Tools > Phils Custom (cms) Checks..., select this check and click "Run...". In Paratext's check window, choose the books and set the options (Options...) before you click OK.
3. Review the results; the error type is shown first to make sorting easy.

OPTIONS
  FinalPunctuation
    Default:  .!?
    Characters that mark the end of a sentence, used by the final-punctuation
    check.

  NonFinalPunctuation
    Default:  ,;:
    Characters considered mid-line punctuation, used by the hanging-word check.

  MinCharsBeforePunct
    Default:  0
    Ignore final punctuation that occurs fewer than this many characters into
    the line. Useful to skip short lines where punctuation placement is
    intentional.

  CheckFinalPunct
    Default:  Yes
    Enable or disable the final-punctuation-followed-by-text check.

  CheckDoubleVerse
    Default:  Yes
    Enable or disable the double-verse-marker check.

  CheckTextBeforeVerse
    Default:  Yes
    Enable or disable the text-before-verse-marker check.

  CheckHangingWord
    Default:  No
    Enable or disable the hanging single-word check. Set to Yes to flag poetry
    lines that end with punctuation followed by exactly one word.
