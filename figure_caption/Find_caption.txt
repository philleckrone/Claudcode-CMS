FIGURE CAPTIONS
===============
Version 1.1

PURPOSE
Scans selected books for \fig figure markers to help review figure captions and
copyright info. Paratext projects use one of two incompatible USFM figure syntaxes
(USFM 2 pipe-delimited fields, or USFM 3 key="value" attributes) - this check
detects which one each figure uses automatically, so no version needs to be
selected.

Results appear in two places:
  - The results list shows one row per figure for the caption (its actual
    text, or "empty" if none), one row for the copyright (its actual text,
    or "Copyright: empty" if none), and one row for the illustration file
    name (its actual name, or "empty" if none). Clicking a row jumps to
    that figure in the text.
  - A FigureCaptions.html report, listing every figure's reference and its
    actual caption/copyright text and illustration file name, is written
    to the project folder and opened automatically in your browser after
    the check runs.
  - Picture thumbnails: when the project's figures folder holds a picture
    for a figure (the same file name, or a .jpg/.png copy of a .tif), the
    report has a "Show picture thumbnails" checkbox at the top. Tick it to
    add a Picture column with a small copy of each picture ("no picture"
    where none was found). Browsers can't show .tif files, so a figure
    whose only picture is a .tif has no thumbnail.

If anything unexpected happens, a FigureCaptionsDebug.log file will appear in
the project folder with the details - please share its contents so the check
can be fixed.

HOW TO USE
1. Install the Phils Custom (cms) Checks plugin with Install_Phils_tools.exe. Everything comes with the plugin: nothing has to be copied into the cms folder. References in the HTML report can be clicked to show that place in Paratext. The first click makes the browser ask whether to open ParatextGoTo, and Paratext follows only when the text window's scroll group follows other programs.
2. In Paratext, choose Tools > Phils Custom (cms) Checks..., select this check and click "Run...". In Paratext's check window, choose the books and set the options (Options...) before you click OK.
3. Review the results list for each figure's caption/copyright text, and the
   FigureCaptions.html report (opened automatically) for the same information
   in one table.

OPTIONS
  DisplayCaption
    Default:  Yes
    Yes includes a Caption column in the report and a results-list row with
    the caption text (or "empty") for every figure.

  DisplayCopyright
    Default:  Yes
    Yes includes a Copyright column in the report and a results-list row with
    the copyright text (or "Copyright: empty") for every figure.

  DisplayIllustrationFile
    Default:  Yes
    Yes includes an Illustration File column in the report and a
    results-list row with the illustration's file name (e.g.
    "CN01629B.TIF" or "MyrrhBush_HK00118.tif") for every figure, or
    "empty" if none is specified. For USFM 3 this is the src="..."
    attribute; for USFM 2 it is the field right after the first pipe.

  SortByCaption
    Default:  No
    Yes sorts the figures listed in the HTML report alphabetically by the
    figure's caption text, so identical or near-identical captions end up
    next to each other for easy comparison. If captions are hidden
    (Display caption = No), sorts by the illustration file name instead
    (if shown); if both are hidden, sorts by copyright text instead. No
    (default) lists them in canonical book/chapter/verse scan order.
    Accented/diacritic characters are ignored when determining sort order
    (but are still displayed normally).
